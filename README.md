# PW486

Minimal landing pages for Donggeon Lim · PW486.

- `/` — SWE project grid
- `/travel` — Traveler timeline

## Stack
React 19 · TypeScript · Vite · React Router · Framer Motion · React Icons

## Data
- `src/data/projects.json` — home cards
- `src/data/journey.json` — travel timeline

## Run
```bash
npm install
npm run dev
npm run build
```
